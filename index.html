怎么玩

  • 走动　点一下地板；电脑上也可以用 WASD / 方向键
  • 互动　点沙发、壁炉、床、桌上的信；或者走近后按右下角的按钮（电脑按 E）
  • 小星　点一点它就能聊天；右上角 ⚙️ 填 API key，📖 是它的记忆本
  • 窗外　跟着你设备的真实时间变化，耐心等一等会有小火车
  • 出门　点右边那扇门可以到屋外，外面没有边界，随便走；点小屋的门回来
  • 镜头　双指捏合放大缩小；电脑上用滚轮
